# 培智AI配音系统 · 更新源

本仓库仅存放**版本更新清单**，供客户端启动时自动检查新版本使用。公开只读。

## 文件

| 文件 | 用途 |
|---|---|
| `version.json` | 更新清单。客户端启动后拉取它做版本比对 |

## 发布新版本的流程

1. 改 `version.json` 里的 `version`（必须大于用户本机版本）与 `update_notes`
2. 提交推送到本仓库
3. 到 Releases 上传安装包（客户端只会跳转下载，不会自动安装）

## 字段说明

- `version` — 最新版本号，格式 `x.y.z`
- `min_upgrade_from` — 强制升级线；本机版本低于此值会显示红色「必须升级」，填 `0.0.0` 表示不强制
- `allow_channels` — 只允许列出的通道收到更新；不填则所有通道可见
- `channels` — 可选，按通道给不同更新说明
- `download_url` — 下载地址，可写完整链接或相对路径
- `update_notes` — 更新说明，一行一条
